# Code of Conduct

## The standard

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be decent to people. Assume good faith, disagree about the
work rather than the person, and accept that a correction to the data is a gift
whoever it comes from.

Unacceptable: harassment, personal attacks, publishing others' private
information, and sustained disruption. The full text linked above is the
authoritative version and covers the rest.

## Scope

It applies in this repository — issues, pull requests, discussions, commit
messages, code comments — and anywhere someone is representing the project.

## Reporting

Mail **oddurs@gmail.com**. Reports go to the maintainer only, and are handled
privately. A security vulnerability is a different thing: see
[SECURITY.md](SECURITY.md).

This is a one-maintainer project, so enforcement is not a committee: it is a
person reading a report and deciding. Expect a reply within a few days.
Responses range from a private word to a permanent block, and the maintainer
will say which and why.
